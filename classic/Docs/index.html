Авторы электронного учебного издания:
1. Валиева Майра Мухаметгалиевна, кандидат экономических наук, доцент кафедры «Экономика и учет», СКГУ им. М. Козыбаева
2. Шинкарев Иван Анатольевич, магистр менеджмента, старший преподаватель кафедры «Экономика и учет», СКГУ им. М. Козыбаева


В электронном учебнике дано систематическое изложение основных макроэкономических проблем и моделей. В каждой теме выделяются вопросы для обсуждения, упражнения, задачи и принципы их решения, рекомендуемая литература. При написании электронного учебного издания были использованы материалы учебников зарубежных и отечественных авторов по макроэкономике.

Электронный учебник может быть использовано для расширения теоретических знаний, а также для приобретения необходимых навыков практической работы с макроэкономическими моделями, поможет сориентироваться в современной литературе по макроэкономике.

Представляет интерес для студентов, магистрантов и специалистов экономических специальностей, обучающихся по кредитной и дистанционной системе обучения, а также для тех, кто интересуется вопросами экономического поведения домохозяйств и фирм в условиях рыночных отношений, их экономических взаимоотношений.
