## Жёсткие правила
- Содержание курса не меняем (`app/data/*` не править), новый учебный контент не выдумываем. Все тексты оболочки — навигация, метакогниция, методические подсказки; русский язык, неразрывные пробелы, «ёлочки», длинное тире.
- Только дизайн-токены (`--bg --ink --accent --d1..--d6 --surface* --line* --ok --warn --bad`), никаких литеральных цветов (кроме печати: чёрно-белое). Две темы (тёмная «Night Atlas» по умолчанию, светлая «Paper»), `.reduce` отключает анимации, телефон 390 px без горизонтального скролла, клавиатура и фокус, смысл не только цветом.
- Ванильные ES-модули, без библиотек и сборки. Свои стили — `app/css/v-<имя>.css`, подключать `loadCSS('app/css/v-x.css')` (из `core/dom.js`) в `load()`. Общие файлы правят только их владельцы (см. вашу задачу). Правки чужих файлов — только перечисленные в задаче.
- Dev-сервер уже запущен: http://localhost:8800/index.html#/… (не запускайте свои; если не отвечает — `cd /home/claude/macroecon && nohup python3 -m http.server 8800 &`).
- Проверка: `python3 /home/claude/tools/shot.py "http://localhost:8800/index.html#/today" --y 0,900 --out /tmp/shots/x` (потом смотреть PNG через Read; ключи `--w 390 --h 844 --mobile --dpr 2 --theme light --wait 1500`), `python3 /home/claude/tools/check.py "#/today" …` (консоль + горизонтальный оверфлоу, 1440/390, обе темы). Для логики без браузера можно использовать Node 22 (есть `node`), подмена `fetch` — см. пример `/tmp/core_test.mjs`.
- **Сохраняйте файлы на диск сразу** и улучшайте итеративно: работа не должна теряться, если вас прервут. Финальный отчёт ≤15 строк: что готово, отклонения, известные недочёты.
