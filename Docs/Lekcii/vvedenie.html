Электронный учебник «Макроэкономика» создан на основе учебного методического комплекса по дисциплине «Макроэкономика» для экономических специальностей.

Предлагаемое издание содержит взаимосвязанные учебные материалы по совокупности проблем современной экономической теории, относящиеся к разделу «Макроэкономика». Предназначено для активизации учебного процесса, имеет оригинальную структуру, которая способствует комплексному освоению учебного курса и овладению инструментами макроэкономического анализа.

В данном сборнике содержатся задачи, упражнения, вопросы для обсуждения, предназначенные для проверки подготовленности студентов к углубленному исследованию макроэкономических проблем и мобилизации интеллектуального потенциала студентов, для активизации самостоятельной работы студентов, их творческого отношения к предмету. В качестве основной литературы рекомендуется использовать учебники В.М. Гальперина, С.М. Игнатьева и В.И. Моргунова, К. Макконнелла и С. Брю, Агаповой Т.А., а также учебники и методические пособия, написанные преподавателями кафедры экономики и учета Северо-Казахстанского государственного университета им. М. Козыбаева за последние годы. Предлагаемый сборник задач, тестов и упражнений дает возможность преподавателю активизировать процесс обучения и оценить знания каждого студента по курсу макроэкономики без проведения специального зачета или экзамена, а также будет полезен студентам для самостоятельной подготовки по макроэкономике.
